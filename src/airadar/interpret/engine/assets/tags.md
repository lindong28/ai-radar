# 分类标签词汇表

分类标签是跨文章的粗粒度主题分类，用于索引和过滤。与关键词的区别：关键词是文章内的具体概念（如 `#poka-yoke`），分类标签是跨文章的主题域（如 `工具设计`）。

**分配原则**：为文章分配某标签的前提是，文章在该标签主题上有实质性产出——经过选择原则（见 `summary_agent_design.md` 第 2.2 节）筛选后，独特亮点、可动手实践、或可复用认知中有与该主题直接相关的条目。仅在行文中提及某概念但未产生上述产出的，不分配该标签。

## 标签结构

标签按**维度**组织。维度按"做什么"划分，每个标签归属一个维度。维度的作用是辅助标签发现和去重，不是严格的分类体系。

维度与用户画像身份层级的关系是**松散对应**：构建/评测/进化偏向研发者（层级 1），应用方向跨层级通用，但不是绑定关系。

## 添加新标签的规则

1. **先查维度**：确定新标签属于哪个维度，然后在该维度内检查是否已有覆盖
2. **避免同义**：不要创建与现有标签含义重叠的新标签（如 `评测方法论` vs `评测设计`）
3. **粒度控制**：标签应是名词短语，描述一个主题域，不是文章特有的术语
   - 好：`上下文管理`（跨文章的主题域）
   - 坏：`Keep-recent-k`（文章特有的术语，应作为关键词）
4. **新维度**：当多个新标签无法归入现有维度时，考虑新增维度
5. **数量节制**：每个维度内标签增长到 8+ 时，考虑是否有可合并的标签
6. **禁止兜底使用**：不要因为没有更合适的标签就默认使用 `AI助手`。`AI助手` 仅用于通用 Agent 平台/端到端自主 Agent 类文章。如果文章的产品方向不匹配任何已有标签，应按规则 1-4 新建标签。
