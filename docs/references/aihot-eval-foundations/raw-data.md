## 需要保留的两份数据

| 数据 | 用途 | 边界 |
|---|---|---|
| Radar 过滤前 raw | 新闻原始输入、来源、URL、正文版本和观察时间 | 使用真实 fetch 在 upsert/prefilter 前保存的 FetchedItem，不用当前业务库补造历史 |
| AIHOT 原始页面/API/SSR 证据及参考值 | 全部动态/精选成员集合，以及可见分数、分类、标签、标题、摘要、推荐理由 | API 字段须能对应网站可观察值；明确空值与未观察到分开 |

Radar raw 位于 `data/raw-capture/runs/`，AIHOT 参照位于 `benchmarks/aihot`。它们可以保存比评测所需更多的数据；派生题集时筛选范围，不删除网站数据。T5 和旧评测 runs 不能作为这次 raw 或参考答案，当前业务库与采集 outbox 也不能补上未归档的历史输入。

[归档实现](../../../src/airadar/fetcher/raw_capture.py) 与 [采集运维说明](../../operations/continuous-eval-data.md) 是现有数据入口。整轮 freeze 只复制归档，不等于已经筛出了合格评测数据。

## 共同来源与连续窗口

期望窗口是 `[2026-09-06T00:00:00+08:00, 2026-09-14T00:00:00+08:00)`，含 9/06—9/13，共 8 天、192 小时。先核对这段数据；有缺口就只选实际连续合格子窗，不拼接零散片段凑天数，不使用当前数据库回填。

来源集合 S 只含在拟用窗口内至少有一次 AIHOT 出现证据、且与 Radar 来源入口语义相同的来源。聚合入口与原站不能只因指向同一 URL 就当同一个源；尚未核清或 AIHOT 窗内未见的来源暂不纳入，不据此断言 AIHOT 永远不采集它。

排除 `wechat_only`、`wx_*` 微信专用来源、微信文章解读、interpret 和 KB 数据，但不按 `mp.weixin.qq.com` 域名排除共同主新闻源的原文。这个筛选只作用于评测，不停止网站采集。

连续性按 S 的实际应采集槽检查：缺轮、来源失败、未完成、损坏正文均不算完整；明确成功空结果可以用；304 需能追到已归档正文。被排除来源的失败不否定 S，自称整轮完成也不能替代逐源检查。小时数来自连续覆盖，不来自新闻发布时间或首尾抓取跨度。

区分发布时间、产品归窗时间和我方捕获时间。现有 AIHOT [timeline_key](../../../src/airadar/eval/aihot_dataset.py) 通常按 discovered 归窗；当 published 比 discovered 早超过 72 小时则回退到 published。保留参照窗口实际规则和捕获时间，不把日窗误称为每一时刻的历史页面快照。

## 共同候选池与逐条配对

S 在合格窗口内的全部 Radar 过滤前新闻构成候选池 U，包括 AIHOT 没有收录的新闻。保留原始观察，再用固定的新闻身份匹配两侧；重复抓取不当多题，集合计数也不重复。这只是准确计算成员集合所需的处理，不新增“身份正确性”或“去重质量”优化维度。

字段题以同源同篇新闻配对，并固定所用 Radar 正文版本。URL 相同不保证正文版本相同；版本冲突不能任选结果好的一版。AIHOT 的模型输入版本不可知时，仍可拟合其可观察输出，但不能把差异全部归因于我方模型。

只有完整捕获 AIHOT 同窗共同来源的“全部 AI 动态”集合，才可把 U 中未出现的新闻标成“未收录”。这是是否收录的 0 标签，不是客观“非 AI 内容”的语义真值。参照捕获不完整时不能这样标，也不能计算声称完整收录拟合的 precision/recall。

AIHOT 已收录却没有 Radar raw 的新闻仍留在收录 recall 的参考分母，另列缺输入数。不能通过删除这些参考项制造高召回；这类缺输入也不是调 prefilter 能修好的。

## 各对象怎样取题

| 对象/题集 | 入题条件 | 参考输出 |
|---|---|---|
| O1 全部 AI 动态收录 | U 中全部新闻；同时保留完整 AIHOT 全部动态参考集合 | 每条是否收录，以及完整参考集合 |
| O2 评分 | AIHOT 有可见数值分数，且有可配对 Radar raw | 可见分数 |
| O3 分类 | 有可观察类别参考且有 Radar raw | 类别 |
| O3 标签 | 有真实标签观察且有 Radar raw；明确空集可入题 | 标签集合 |
| O3 标题 | 有可观察标题参考且有 Radar raw | 标题 |
| O3 摘要 | 有可观察摘要参考且有 Radar raw | 摘要 |
| O3 推荐理由 | 有可观察推荐理由且有 Radar raw | 推荐理由 |
| O4 精选成员 | 固定时间窗的完整候选池、固定分数及完整 AIHOT 精选参考集合 | 精选成员集合 |

各字段独立筛选：缺分数不影响分类/标签/文本题，缺推荐理由也不丢掉其他字段。未知标签、未捕获字段或页面未提供的值不填成空答案；AIHOT 未公开的内部维度分和 opinion 不另造参考。

O4 第一轮只需固定池和已计算分数来调选择规则，不重建 AIHOT 内部运行。若沿用 Radar 累积归档，记录并固定所用初态即可，不要求还原全部生产历史。

## 最小留存与当前状态

固定原始输入、参考及其配对关系，开发题和回归题分开；同一新闻/版本不跨组反复调答案。保存每题预测和必要判词，运行结果引用题集与对象版本，不另建分层账本。

本轮没有冻结数据或生成题集。数量应在实际来源和连续窗口核对后再报告，不使用旧十四日统计、单轮抓取行数或未筛选的全量归档冒充合格题量。
