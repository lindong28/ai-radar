# 被评测对象、自动指标与建题方法

> [Developer] · Mutable snapshot · 2026-09-16 · 前置定义提案；指标未设达标阈值，题集/判官/执行器未实现。数据边界见 [raw-data](raw-data.md)，最终维度 D1—D9 见 [总览](README.md)。

## 通用计分约定

O1—O3 是三类直接 LLM 组件；O4/O5 是嵌套组合对象。组件题可固定其他阶段用于归因，但必须标注绕过了什么；只有组合题沿真实 gate/状态/页面执行才回答产品效果。组合中的确定性代码不新增 LLM 判官，能直接比对的字段用确定性指标。

参考输出未知时不计入对应质量分母，必须报告该字段参照覆盖率；模型输出失败/缺失不得作为“参考未知”丢弃。所有指标同时报告可计分题数、缺参照数、模型失败数及来源/日期/版本构成，不用一个总平均掩盖子维度。

确定性标签比较只使用冻结的无损规范化/已核实同义映射。不能先删除候选额外标签、把未知类别填成我方多数类，再报告高一致率。跨系统类别体系若不能逐条映射，先标映射未定，不能直接比较代码枚举字符串。

计数分母为 0 时指标为 N/A 并报告数量，不伪造满分；特别约定空集匹配的地方在下文明确写出。无输出在集合指标视为空预测并计失败，在数值/语义指标中单列不可计算与完成率，不能仅展示幸存输出的优异均值。

本轮只定义候选指标及题目构造，不决定样本比例、题量、模型/判官选择、调用预算、阈值或加权总分。LLM 语义评分是待校验的自动化读数，不因能自动执行就已可采信。

## O1 · 新闻准入组件

**目标与边界。** 覆盖 D4/D7 的入场资格，防止 AIHOT 已展示的新闻在我方前段被丢弃。直接对象是 [prefilter runner](../../../src/airadar/prefilter/runner.py) 的判断；[scorer](../../../src/airadar/scorer/runner.py)、[enrich-v2](../../../src/airadar/enrich/runner_v2.py) 的生产准入与 [timeline](../../../src/airadar/web/routes/timeline.py) 的相关性 gate 另记阶段轨迹，在 O5 验证，不能都归咎于 prefilter。

**输入/输出。** 输入为一条符合数据准入的原始版本及生产实际使用的源信息；输出为 prefilter 结构化结果与调用错误。下游是否实际处理/展示作为组合输出，不混入该组件的直接输出。

**题目单位与建题。** 从 S 的完整过滤前池按新闻/输入版本派生题，运行时不提供 AIHOT 是否收录的标签。可配对的 AIHOT 可见条目标成“可见正例”，其中精选再标“精选正例”；其他原始候选保留为未标注，不因未见 AIHOT 而成为负例。同版本重复观察不重复增加独立单条题权重。

**参考与分母。** 令 V 为有合格 raw 的 AIHOT 可见正例，F 为其精选子集，P 为该组件明确通过的题。缺 raw 的 AIHOT 条目另报参考覆盖缺口，不加入 V 冒充可运行输入。

| 自动指标 | 口径与方向 | 限制 |
|---|---|---|
| 可见正例保留率 ↑ | `|P∩V| / |V|` | 调用失败、不通过均不是保留；V 为空则 N/A |
| 精选正例保留率 ↑ | `|P∩F| / |F|` | F 为空则 N/A；不等于最终精选召回 |
| 调用/结构错误率 ↓ | 失败题数 / 所有尝试题数 | 不把失败当正常拒绝 |
| 全池放行率、各 gate 丢失数 | 放行数 / 全池题数；按阶段定位可见正例损失 | 诊断而非“越低越好”目标 |

自动保留全部新闻的基线在正例保留率上就是 100%，必须一起列出，避免把此指标当全面分类能力。没有真实拒绝标签时，不报告二分类 precision/F1/accuracy，也不为追求这三个数字凭空创造负例。是否增加人工标注留待用户决定。

## O2 · 新闻评分组件

**目标与边界。** 为 D1/D4 提供评分与排序信号。入口是 [scorer runner](../../../src/airadar/scorer/runner.py)、[评分 schema](../../../src/airadar/scorer/schema.py) 及 [weighted_score](../../../src/airadar/curator/score.py)。schema 含 relevance、density、recency、authority、engineering 和可选 significance；旧函数名/旧记录不能据此改称五维系统。

**输入/输出。** 输入为单条 raw 版本、来源属性及该题时钟；输出为维度分、reasoning/topics 与真实聚合后的 raw score。精选阶段的类别排序系数、入选后分数变换属于 O4；页面整数化/分档属于 O5。保存三者的关系，但不能把它们当同一分数。

**题目单位与建题。** 从有 AIHOT 可见评分的配对题派生评分题，以 raw 构造生产输入、以 AIHOT 的外显分数作外部参照。固定组件题可以直接运行评分以隔离 O1，报告“强制评分”；另在 O5 统计真实准入后覆盖，不能静默只测通过 prefilter 的容易子集。

**参考与分母。** AIHOT 外显评分不提供六维内部真值。若其分档而非数值才可见，只比较可见分档，不能倒推精确分。未知参考值不当 0；raw score 常量、样本不足或秩不可定义时相关指标为 N/A。

| 自动指标 | 口径与方向 | 限制 |
|---|---|---|
| Spearman ρ、Kendall τ-b ↑ | 同一可比来源/时段池内，raw score 与 AIHOT 可见评分的秩关联 | 仅条件相关/诊断，不是最终显示分准确度；报告 ties、n 和失败覆盖 |
| 输出完成率 ↑ | 有合法评分输出数 / 尝试题数 | 六维缺失/可选项状态单列，不能把失败样本丢掉 |
| 维度有效率 | 范围、必需字段与结构校验 | 只证明结构合法，不是六维 accuracy |
| 受控池排序差异 | 与 O4 同池下游选择差异关联 | 不用全局 pooled 相关替代逐池比较 |

参照常数/开发集固定统计量基线须在开发阶段确定后原样用于回归：常数评分会使秩相关不可定义，这本身要如实呈现；开发集可见评分中位数可为 O5 显示分 MAE 提供不读测试答案的简单基线。禁止用测试集真分数/类别决定候选排序来声称模型拟合。

最终显示分 MAE 不在 O2 直接验收；只有 O5 跑过实际页面评分变换后才计算。raw 排序改善而最终分变坏是可以发生、也必须保留的结果。

## O3 · 内容富化联合组件

**目标与边界。** 覆盖 D2/D3/D5/D6。生产候选路径 [runner_v2](../../../src/airadar/enrich/runner_v2.py) 一次联合生成 [schema_v2](../../../src/airadar/enrich/schema_v2.py) 中的 `primary_category`、`is_opinion`、`tags`、`title_zh`、`summary_zh`、`why_recommend`。子维度分别计分，但不虚构六个独立生产调用。

**输入/输出。** 输入为一个 raw 版本与真实源上下文；输出同时保存 provider 原输出、生产 normalizer 后结构化值。组件 tags 经 [provider normalizer](../../../src/airadar/enrich/normalizers/production_enrich_provider_output_v2.py) 处理，网站 [presentation](../../../src/airadar/presentation/summary.py) 还会再次做标签投影；后者归 O5。

**题目单位与建题。** 对合格配对新闻建立一题，引用同一原文与 AIHOT 各个可见字段，逐字段记录 known/明确为空/隐藏/unknown。题可只具备部分字段 gold；不因缺推荐理由就丢弃可计分类和标签的新闻。精选理由题另按 AIHOT 精选状态构成子集；非精选缺理由不自动视为空理由目标。

**类别与 opinion。** 当前 v2 类别为 model/product/industry/paper/tutorial，`is_opinion` 独立。先核对 AIHOT 页面到类别的映射；AIHOT 未提供 opinion gold 时只记我方输出诊断，不生成 opinion accuracy。

| 子维度 | 自动指标与方向 | 分母/空缺处理 |
|---|---|---|
| 类别 | 逐题 accuracy ↑、按参照出现类别的 macro-F1 ↑、混淆矩阵 | known 类别题；缺候选输出算错并入缺失列；明确未分类另报比例/一致性，不折进五类；列出 macro 类集合 |
| 标签 | exact-set ↑、micro precision/recall/F1 ↑，补报每题 Jaccard | 仅 known 标签题；保留全部候选额外标签，已核同义项才归一化 |
| 标题 | 事实支持、关键主体/事件一致、语气与立场、误导性 | 待校验语义判官分别评分；保留原文与参考标题，不只比措辞 |
| 摘要/可见正文片段 | 关键事实覆盖、事实支持/幻觉、信息重点与编辑角度、立场一致 | 待校验语义判官；长度/重复率仅诊断，不是接近度验收 |
| 推荐理由 | 对应文章的具体事实依据、推荐逻辑、编辑角度、无通用套话 | 只在可观察参考理由的题上拟合；原文 grounding 与参考相似度分开 |
| 联合结果 | 调用/结构错误率 ↓、各字段完成率 ↑ | 所有尝试题都计；不能因某字段失败而隐去整题 |

标签计算令每题参考集合为 G、候选为 C；累计 `TP=Σ|C∩G|`、`FP=Σ|C\G|`、`FN=Σ|G\C|`，micro P=`TP/(TP+FP)`、R=`TP/(TP+FN)`、F1=`2TP/(2TP+FP+FN)`。某项分母为 0 则该项 N/A。两边明确空集时 exact-set 和每题 Jaccard 记 1，但必须单列空集题比例，避免全空题掩盖有标签题表现；全集都为空时 micro 指标仍 N/A。

标签 unknown 不转 `[]`；页面隐藏不等同真实空集，O3 只能在确有标签 gold 的子集计内容，隐藏/显示由 O5 计。已知非空参考而候选缺失时按空预测计 FN，同时记字段失败。

“两边明确空集”只适用于成功返回的已知空集合。候选调用失败或标签字段缺失即使参考为空，也不得取得 exact-set/Jaccard 的空集满分；这些题的逐题集合一致性记 0，另外计失败。micro 计数在参考也为空时不能表达这种失败，故必须与完成率联读。

类别 macro-F1 中，参照出现而候选从不预测的类 F1 为 0；没有参照支持的类不混入宏平均，额外预测仍进入混淆和 false-positive 计数。空类单列，不能为了高 accuracy 把它们悄悄剔除后不报占比。

文本语义判官会自动处理，但其 rubric、对照样本、人工校验与偏差检查属于后续 L1 的判官/校验设计。未经校验的读数只作诊断；不拿 ROUGE、字符重合或另一个未校验 LLM 的单一总分宣布语义达标。

## O4 · 精选组合 workflow

**目标与边界。** 负责 D4，并解释 D1/D5 的状态变换。对象不是新 LLM call，而是 O1—O3 输出驱动的 [curator/select.py](../../../src/airadar/curator/select.py)、[score.py](../../../src/airadar/curator/score.py)、去重和 [curated_archive](../../../src/airadar/web/routes/curated_archive.py)。既测单轮选择，也测累积归档，二者不互相冒充。

**输入/输出。** 输入是一段连续窗内 S 的完整候选池、逐轮输入可用时刻、来源/类别/分数状态、受控时钟，以及窗前 warm-up 和归档初态。输出为逐轮成员/分数/理由状态及在指定观察时点可见的精选归档集合/顺序；生产配额、阈值、去重等实际参数保留为运行身份。

**题目单位与建题。** 一题是“完整池＋初态＋事件序列＋观察时点”，不是一条新闻。按 raw 时序注入隔离状态，运行实际准入、评分、富化与 curate，再读取归档；组件消融时必须只替换指明阶段并保持同池同初态。计分窗前 warm-up 不与计分样本混计。

**gold 分级。** 完整且时点可比的 AIHOT 可见精选集，可以作可见集合 gold；只有日级快照/条目 selected 字段时，只作同窗同源可见集合拟合，不能称为 AIHOT 精确当轮选择真值。AIHOT 内部候选池通常不可知，显式记录我方受控池的可比程度。顺序没有参照证据则 N/A。

令 R 为该题符合范围的 AIHOT 可见精选身份集合，C 为我方同一观察面完整输出集合。R 中缺 Radar raw 的条目保留在总体覆盖账中；另列可运行配对子集指标，不把这个子集改称完整 R。

| 自动指标 | 口径与方向 | 限制 |
|---|---|---|
| 精选 precision/recall ↑ | `|C∩R|/|C|`、`|C∩R|/|R|` | 报参考覆盖缺口和可配对子集读数；各自空分母 N/A |
| 精选 Jaccard ↑ | `|C∩R|/|C∪R|` | 双方为空时记 1，单列空池，不证明选择能力 |
| 选择数与错选/漏选数 | `|C|`、`|R|`、`|C\R|`、`|R\C|` | 不用参照精选数量作为预测 k |
| 顺序一致率或 NDCG ↑ | 顺序一致率=同向可比项对数/可比项对数；NDCG 仅在固定相关性定义和截断范围后使用 | 无顺序证据或无可比项对为 N/A；不能按分数私造参考顺序 |
| 重复/错误归并率 ↓ | 重复展示或错误合并的身份组数及条目数 / 可核对组数及条目数 | 事件相似不自动等于重复新闻，身份不明单列 |

不使用只含 selected 的题池，不用 AIHOT 当日入选数 oracle k 代替真实我方选择，不把类别占比相近作为逐输入集合拟合的验收。原始候选的额外项与参考漏项都要出现，不能只在交集上计算漂亮数字。

双方空池的 Jaccard=1 也只适用于成功运行、确认无输出的场景；执行失败不是有效空集合，记失败与不可计算，不获得空池满分。所有集合指标附带场景运行完成率。

## O5 · 最终用户可见内容端到端

**目标与边界。** 覆盖 D1—D9，将 O1—O4 与真实路由、presenter、前端组合起来。`/` 和 `/all` 是已定位入口，不默认它们穷尽全部共同内容面；日报、热点、媒体/相关信息须先核 AIHOT 是否提供及参照是否完整，再纳入对应场景。

**输入/输出。** 输入是 O4 的受控数据/状态、观察时刻与明确页面条件（路由、类别、日期、分页及影响内容的视口状态）；输出是读者实际能看到的条目、顺序、文本、分数、标签、来源和链接行为。中间 API/DOM 是证据，不自动等于最后的可见输出。

**源码接合点。** [presentation/summary.py](../../../src/airadar/presentation/summary.py)、[timeline](../../../src/airadar/web/routes/timeline.py)、[curated_archive](../../../src/airadar/web/routes/curated_archive.py)、[categories](../../../src/airadar/web/routes/categories.py) 和 [app.js](../../../web/static/app.js)。timeline 能覆盖精选项的分数/理由；前端会整数化分数且某些列表隐藏 tags。普通新闻详情路径会跳到原文，不凭空设“本站生成长正文”目标。

**题目单位与建题。** 一题是“受控序列/初态＋页面查询/观察条件＋AIHOT 同面参考”。优先由 O4 题派生精选场景，并用完整普通候选派生普通列表/类别场景；同条新闻可在多个面观察但保留共用身份，避免当成独立新闻加权。无可重放同面参照的场景标未测，不拿别页字段代替。

| 最终可见指标 | 口径与方向 | 关键分母/限制 |
|---|---|---|
| 显示分 MAE ↓ | `Σ|s_radar−s_aihot| / n`，s 是最终可见数值且量纲一致 | 仅有双方可见数值的配对项；缺候选分数另计缺字段，不当 0；同时报可计分覆盖 |
| 显示分偏差/分档一致率 | 平均有符号误差；同参照分档一致数/known 分档数 | 分档边界须从真实页面核实；未定义则不计 |
| 分类/标签/文本/理由 | 复用 O3 指标，但候选换成真正可见值 | 覆盖、fallback、截断后的文本不能拿 enrich 原值代替 |
| 可见性一致与缺字段率 | known 参考的显示/隐藏状态逐项比较；应显示却缺失数/应显示字段数 | 明确隐藏、明确空和未知三分；未知不参与但报覆盖 |
| 漏项/额外项与集合指标 | 沿 O4 集合定义扩展到普通列表和分类/日报等同面集合 | 固定页范围、查询和时点，不能拿单页对全库 |
| 列表/分组/去重 | 顺序项对一致、分组归属一致、重复与错误合并数 | 仅有可验证顺序/分组真值时计算 |
| 原文与事实身份 | 来源/作者/时间逐字段一致，链接指向同文章身份；媒体/相关信息关联错误计数 | 无参照字段则 unknown；域名相同不算链接身份相同 |

页面最终分数和标签的比较需保留可见状态。两站某页都不显示分数时，该页不是评分 MAE 样本；一侧应显示而缺失时先记显示缺陷，不能静默缩小分母只报 MAE。文本输出为空也不能靠语义判官跳过而消失。

确定性的 API/DOM 抽取要接真实 consumer，并至少实际打开页面读内容、检查隐藏/截断/回退和原文跳转，才可称为最终可见验收；本轮未运行这些验收。组件读数全好而 O5 仍差时，先定位具体路由/状态/呈现转换，不必先改 prompt。

## 后续三层设计的接续点

每个对象保留自己的题目单位、分母、证据限制和子维度；后续 L1 展开计算/判官/指标校验，L2 固化 raw 到题到输出的资产引用，L3 固化身份、可比性与采信边界。这里的未知不得在实现时用默认值消失。

没有实际连续池就不运行并报告 O4/O5 的完整历史拟合；有合格逐条配对也可以先准备 O1—O3 的建题，但必须标注组件范围。反之，端到端有问题不能只报组件已经达标；本轮尚无任何对象的新运行成绩。
