# 用五维语义假设研究 AIHOT 可见分

Status: accepted for offline experiment · 2026-09-21

用户要求按作者设计优先进行多轮优化，目标 MAE < 3。采用五维 LLM 输出＋代码显式权重组合；不修改题库、gold、计分器或生产，不部署、不 push。原文只公开结构，没有公开具体维度和公式，以下均为可被实验否定的假设，不能称为原作者实现。

首候选 impact / novelty / substance / authority / relevance 分别表示事件影响、变化幅度、原文实质信息、主张来源资格、AI主题关系，各0–10整数。0/5/10分别锚定无该价值／中等明确价值／极罕见或充分价值，完整刻度由版本化 prompt 保存。固定35/20/25/10/10权重把80%分配给事件与内容；来源资格不等同公司知名度，主题关系不设常量底分。首轮不额外按来源tier加权，避免与authority重复计入。相比旧三维S2，这一拆分将来源和主题关系与事件价值区分；旧五维含本项目工程偏好，直接总分和后置仿射校准不作为主方向。

复用 `aihot-score-pointwise/v1`，固定开发200（`score-dev-20260920`），原始输入白名单及5000字符正文边界不变，reason先于五个分数。先smoke3验证执行，再开发同题比较；按误差提出下一轮假设，不向模型输入参考分。开发有支持后冻结候选，在未参与调优的回归样本验证，排除9/20两批各200题；事件级独立性按实际可取得证据报告。五次不同紧凑设计是归因汇报节点，不是未达MAE<3也算完成。每轮原件及结论保留在既有 runs/experiments 分区，复算组合不冒充重新调用。

已知边界：作者维度、公式、九月模型仍未知；此前S2开发MAE11.015、回归10.160；新五维收益未测。条件权重若要加入，须先写具体输入规则与消融假设。Flash优先，模型变化须同题单独比较。无限预算不等于无限重复无信息实验。

决策评审：独立 `/root/author_score_decision` 首轮要求补齐维度刻度和组合依据；补齐并明确首轮不加tier条件后，第4项复核成立，其余六项成立，放行。仅放行离线研究，不构成有效性结论。
