# 分类竞争证据路由指导实验

日期：2026-09-22。状态：accepted for offline experiment。用户继续授权从最有希望的历史方案与局部修复组合迭代。继承[81af](20260922-81af-test-blind-conditional-category-review.md)、[c931](20260922-c931-continue-category-research-from-best-candidate.md)和[5f6a](20260922-5f6a-test-category-contribution-and-review.md)的离线边界，不覆盖历史读数。

## 决定

以C5为整体对照、I2为局部研究组件，增加默认空的`--routing-guidance`，UTF-8文本只追加首轮routing prompt，完整文本进入behavior身份；需要同时开启conditional-review。第二次仍为同一Flash盲复核，保留I2局部指导，不提供gold或案例身份。输出保持reason、needs_review、primary_category顺序和既有解析契约，默认与失败留分母行为不变。

I阶段77个首轮错题仅路由12个，26复核修6/退4，76题已见回归净退2。原ROUTING已要求相邻类别证据/主体冲突触发；本轮是重新构框这些未兑现的条件，不是从纯自信路由换成全新独立检测器。同一模型仍自报flag，效果待测。内容的主题对象与文章实际交付的证据可竞争；短而类型明确的内容不因缺细节自动成为无类型。

## 范围、替代项与验证

固定dev200，至多两个候选和一个原样C5控制，冻结一个有理论及局部依据的候选覆盖361已见题；最多1722调用，8worker共享池、90秒超时、无重试/fallback。第二候选根据首轮结果改路由或复核指导，不同时盲加机制。分别量首轮变化、同次复核修正/退化、错误路由覆盖及六类P/R，失败仍计分；开发和回归均已曝光，不称独立泛化。此阶段两个开发arm及冻结终态后停止，不以重复采样挑有利波动。

暂不重复原I2、全池无条件双调用或全局叠加规则：前者漏掉65/77错题，后二者有真实复核退化及H3整体退化证据；不据此否定整个方向。既有C5控制可先独立运行。没有修改gold、题库、六类定义或生产A0，金额未定价不等于零。

一轮独立决策审查七项成立。审查修正了“旧路由只是自信判断”的不准确描述，已收窄为竞争证据条件的提示实验；该修正不新增机制。路由改善、复核质量与成本留待实测，结果归[O3状态](../evaluations/content-enrichment/status.md)。
