# 分离当前评测入口与历史、原始参照资产

Status: accepted · 2026-09-20

## 目标与决定

用户要求修复 `benchmarks/`、`runs/` 的目录问题，允许清理预计无用的历史资产。采用迁移而非改写历史：AIHOT 原始参照 gitlink 从 `benchmarks/aihot` 移至 `data/aihot-reference`，保留同一 commit；33 轮旧 schema1 共享池运行及实验元数据移至 `data/evaluation-archive/{runs,experiments}`，保留原 benchmark/version；四个顶层预检和人评迁移目录归入标准 news-admission 运行分区的 support 材料，标记为资产迁移而非模型运行。

读兼容通过精确前缀映射与共享 resolver 实现，覆盖已移走的外部题库、历史运行和指标来源。冻结载荷、标签、manifest、原票、模型输出与叶子成绩不改；总表仅重建实际位置投影。新运行仍用 `vN` 和真实 UTC 创建时间。

删除范围为零：尚不能证明备份没有独有内容，随 support 迁移。没有把历史资产复制成新 benchmark、重算成绩或增加评测调用。旧采集工作树保留其自己的目录契约，本次不操作调度或生产。

## 证据与替代项

审计核到 121 轮正式记录、261 行可回读指标，其中 33 轮使用旧版本名；38 轮旧 prefilter 的 dataset 原路径缺失，已搬归档的同一题库可加载 11,804 题且 manifest 摘要一致。四个非标准 runs 根目录含 99 个文件。原始 AIHOT 子模块仍被采集和旧评测代码消费。

删除全部历史会损失复现和人评证据；改名为 v1 会伪造历史身份；只改说明不能修复真实 loader；在根目录留下兼容副本会继续混淆当前入口。因此保留内容、迁移位置，并让消费端明确解析旧引用。

## 历史边界与验证

ADR-060 的双仓、冻结 manifest 与 exact commit 约束保留；20260913-c7d4 的既有采集 push 权限不外推为本次 push 授权；20260917-b8e2 的独立采集 runtime 不动。assets.md 先前保留顶层目录是当轮整理边界，本轮用户已授权继续迁移。

实施前尚未验证：迁移脚本、逐文件字节对账、索引来源回读、38 轮题库消费者、子模块新路径和旧 pinned runtime 兼容。验收须实际读取消费者，不以目录计数代替；保留路径映射和迁移收据用于恢复。

独立 decision-review：migration_decision_review 首轮七项中 4/7 因未列明删除对象而待核；将删除范围收窄为零后复核全部成立、放行。评审没有修改代码；实施正确性另行验证。
