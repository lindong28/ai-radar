# ADR-019：单篇解读成本只与自身可比前窗对照

- 状态：Accepted；interpret cache 精确覆盖 gate 由 ADR-020 supersede
- 日期：2026-08-11
- 范围：每周 LLM 成本报表的 `单篇解读` 行；不定义 P3 成本目标、解读质量或账单实付

## 决策

保留每次成功 interpret 调用的已知平均成本，并以报告的前一等长窗口中同一指标作为参考。只有当前窗与前窗都存在 interpret 调用，且两个 interpret cohort 自身的 cache 测量覆盖率按整数交叉相乘精确相等时，才显示前窗金额与变化率；任一条件不满足时明确显示参考不可用及原因。报表级总覆盖可比不能替代 interpret stage 的可比性。

不使用 ¥0.06 作为本行当前参考：它是 P3 完成 prompt/cache 改造后的目标，不是 P2 的历史基线。也不删除本指标，因为 interpret 单位成本是已批准的周报优化指标；阶段总额已在另一行展示，不能代替单位成本的判断参照。

## 取舍

前窗变化会包含 token 量和模型组合变化，这正是成本驱动分析要保留的信号，但不能据此推断解读质量。cache 口径过渡期会暂时失去参考；显式不可比比发布一个受采集口径影响的百分比更可信。所有金额继续按 priced + nominal 目录价派生，并非账单实付。

## 验证边界

验证两窗均有调用且 interpret 覆盖相等时显示前窗金额/变化率；interpret 覆盖不等时，即使总窗覆盖碰巧相等也不显示；前窗无 interpret 调用时给出独立原因。独立决策评审初次指出 stage/总窗交界面，收窄后复核放行。
