# 无示例评分刻度与独立维度调用的离线对照

Status: accepted for offline experiment · 2026-09-21

后续修订：用户明确提出 few-shot 后，[f6b3](20260921-f6b3-test-editorial-evidence-score-rules.md)仅在编辑机制研究中放宽无示例限制。下文保留本轮当时设计与读数，其它边界不变。

用户本轮偏好不依赖示例，授权分析大残差、调整刻度/权重、试验逐维独立调用，并通过 HTML 裁决疑似不合理的 AIHOT 参考分。本轮保持五维35/20/25/10/10组合、Flash、同一开发200题（seed `score-dev-20260920`）和原始输入不变：A9只细化 impact 中对 AI 的具体影响；A10保留A2各维刻度、拆为五次调用，每次只见一个维度与同一原始输入。总调用并发上限8，来自已验证的单批容量；每题五次串行，不乘成40并发。先smoke再同题开发，只有取得改善证据的冻结候选才进入新的未参与归因材料。

不使用 few-shot、参考分输入、后置数值校准，不自行剔除题目。A2开发MAE9.510、Spearman0.66696是对照，不是生产分数。有限权重网格仅改善0.115，不优先重复；不外推成所有权重方案无效。MAE<3仍为目标，Spearman用于同时观察排序，无新增硬阈值。失败、退化结果也归档。

大残差复核页展示原始输入、实际prompt、模型原始reason与维度、参考分、agent分析及反方解释。A2只有一个总reason，不编造逐维模型理由。票默认未评，`retain`仅表示暂保留题目，不等于确认参考数值；`exclude`是评分题剔除建议，用户回传前不生效，也不影响其它对象。输入缺口与参考分争议分开。

本决策窄替代[ae72](20260920-ae72-test-semantic-score-dimensions.md)的“暂不拆多次调用”，依据是用户本轮明确允许实验，不代表额外调用已证明有益。[52af](20260921-52af-test-author-inspired-five-dimension-scores.md)的五维、reason-first、离线及冻结回归边界继续适用。不修改生产、题库、历史实验，不push。

独立决策审查：`/root/score_experiment_decision`，基线db55378，七项均成立、放行，无blocker或基线独立新发现。两项提示已吸收：A2已有事件/引用规则，重复它们不能冒充新机制；复核票不映射为既有人评`keep`。审查放行的是实验设计，不是收益或gold错误的结论。

同一授权内追加A11：A9开发MAE11.080、Spearman0.636，不采纳；尤其腾讯会议输入只有一句正文，A9仍称信息具体，Sketch输入已有引用却仍称无官方信息。因此A11保持A2全部维度刻度与单次调用，只把reason改为先列“已提供/未提供”的证据边界（180字上限），检验输出组织是否减少这类错误；没有示例、分数校准或生产额外依赖。此为有具体失败依据的低反转成本prompt消融，L0，不再为同一研究方向购买外部决策审查。A9失败不支持“模型能力不足”的结论。
