# 分类输入材料修复与同题消融

日期：2026-09-27。状态：accepted for implementation and offline evaluation；未部署。独立 decision-review `category_input_decision` 七项成立，无 blocker 或应修。

用户要求已知数据缺口和逻辑问题不因分数变化而搁置。实际 M2 人评48题有8条显式引用关系，仅2条原帖进入模型；web来源被正文补全跳过，引用仍截至4000字，部分冻结AIHOT长正文及原文tab未使用。

在原有X时间线请求中请求直接引用扩展，保存在原始extra，由分类生产输入读取；缺失仍查询本地已采集数据，不引入生产逐条实时lookup。离线通过独立prepare工具补读身份绑定的冻结原文和一次批量当前X lookup，以既有body-context契约冻结；保留来源、抓取时间、完整性和原输入摘要。既有as-of引用、题目、参考答案、人评和历史成绩保持原样。补全材料单独核对同一原文/引用身份；发生实质新闻变化不自动迁移人评。片段不是全文，晚采不是历史可得。

先以M2原规则运行同48道人评开发题，之后依据错题调整研究候选，模型和计分口径不变。保留失败分母；全部为已见数据，不称盲测。人评只进入计分。生产分类默认不因实验提升而切换。

备选的扩大as-of截止会混淆时间，摘录单独不足以修全文，生产逐条lookup增加请求和延迟；同请求扩展与独立冻结覆盖当前需要。当前API可用性、材料历史版本同一性、实际覆盖及模型收益尚待实测；费用有界但不能收回。沿用ADR-53ab允许的补抓边界，不修改准入评测的历史时间契约。
