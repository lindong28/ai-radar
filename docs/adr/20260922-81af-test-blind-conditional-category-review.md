# 分类条件盲复核与局部证据指导

日期：2026-09-22。状态：accepted for offline experiment。一轮独立 decision-review 七项成立；仅批准实验，不证明效果或授权生产采用。继承 [5f6a](20260922-5f6a-test-category-contribution-and-review.md) 与 [c931](20260922-c931-continue-category-research-from-best-candidate.md)，不覆盖其原始读数。

## 决定和依据

用户要求继续从理论与实测最有希望的方案及有效局部修复组合接续。以 C5 全文＋as-of 引用贡献为整体对照，在既有条件复核中增加默认关闭的 `--blind-review`，二次不提供初判及 reason；可选 `--review-guidance` 只影响二次调用。两者仅在 `--conditional-review` 下有效，首轮、二轮 prompt、reason、调用及同首轮指标分别归档。失败不隐式回退，不删除分母。

H3 全361题274对、同期C5为286对，13修正/25退化；局部收益不能靠全局叠加兑现。旧B4额外16次复核零改类是相关反证，不能外推为所有两阶段分类无效。盲复核只是假设：减少初判锚定，并把局部边界说明限制到不确定样本；不是已测原因。

## 实验与边界

固定开发200题：同期C5控制、I1条件盲复核、I2基于I1归因加入局部指导，最多1000调用；若有理论和局部证据支持，冻结一个候选扩到361已见题。C5不是生产默认；生产A0、gold、题库和计分器不改。无新抓取、来源白名单或参考答案进入模型。Flash、temperature=0、8worker共享池、90秒请求超时、零重试/fallback；每个有限批次终态后再决策。

分别统计路由覆盖了多少首轮错误、复核修正/退化、六类P/R、总调用和usage。重跑首轮的两个arm只构成workflow比较，不能单独证明guidance因果；没有同期带初判复核对照，也不能证明旧B4失败由锚定造成。额外85开发题和76回归均已曝光，不称独立泛化。

全局再加规则和全池无条件双call本轮不选：前者已有跨类退化，后者扩大成本和干预面；不改变默认是回退点，已发生API费用不可收回。路由覆盖、盲复核净收益、指导词效果均待此次实测。结果、失败及下一研究归属回写 [O3状态](../evaluations/content-enrichment/status.md)。
