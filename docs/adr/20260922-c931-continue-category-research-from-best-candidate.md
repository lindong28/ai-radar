# 从当前最优研究候选接续分类实验

日期：2026-09-22。状态：Accepted for offline experiment。用户授权每轮综合全部已知候选的理论与实测自主择优；本轮选择B1开始，不将此写成用户点名选择B1，也不改变生产A0或gold。继承[5f6a](20260922-5f6a-test-category-contribution-and-review.md)的资产与输入边界；本决定更新研究路线，不推翻其历史实测结果。

## 决定

从具体FP/FN的输入与reason提出最小假设，比较研究成果/实践/观点、现实事件、产品介绍等分类边界；每轮从全部已知候选择优，不把最新编号当赢家。先固定200开发题做至多六个arm（含同题原样重复控制），再冻结至多两方案覆盖361题。所有361题均已有历史曝光；既有76题只能称回归，不称新独立集。十三项确定性指标和六类P/R双90目标不变，没有新增LLM判官。

增加默认关闭的来源上下文开关，只投影冻结input中url、author、source_kind、source_name四个非空字符串；author可能为feed提交者，source_name是采集渠道。不提供来源到类别查表，不加入AIHOT派生字段，不实时查询。开关和实际prompt进入对象身份；不开启时保持原prompt逐字一致。具体结果若不胜仍保留诊断能力，不自动纳入研究配置。

全文继续复用已有`--body-limit 0`，只取消冻结正文截断，不新增抓取依赖。各候选每题一次Flash、temperature=0，共享池8worker、90秒单请求超时，无重试/fallback。既有子集真实变化与未变prompt组分开归因，更多信息和更长prompt不天然更好。

研究起点与已证改善分开：理论适配、可接受成本及同口径成绩支持继续研究，不需要先证明所有机制有效；但不得将未变输入组的随机收益归功干预，不绕过关键退化或生产授权。用户本次已授予研究择优权，不逐轮重复询问。C5在开发补全文19题14→17对，成为冻结研究候选；验证后可以依据实测再更新研究选择，不能改完prompt仍称冻结验证。

## 替代项与审查

不靠来源白名单硬贴标签，不将AIHOT生成摘要/参考类别输入模型，不因标签可疑直接改gold。旧B3行业过度吸入、B4自报歧义复核零修正、B5组合未胜作为反证保留；不据此断言所有边界澄清或多调用workflow无效。

独立决策审查覆盖本阶段边界和来源输入增量；来源语义警告已在真实prompt中说明。实现审查无遗留finding，49项定向测试涵盖四种来源字段投影、默认开/关真实runner、六类计分、引用哈希/时点与复核失败；实测输入规模及最终结果见[O3状态](../evaluations/content-enrichment/status.md)，原审查存C阶段首轮support。没有部署或推送。
