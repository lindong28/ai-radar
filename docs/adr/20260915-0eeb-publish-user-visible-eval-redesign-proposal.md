## Decision

备选包括继续扩充旧组件指标（未覆盖最终转换）和同时重写产品推理链（会在取得基线前混入变更，且超出本轮）。本次选择先设计终点测量，不预先选定下一轮应修改的模型、prompt 或排序策略。
