## 产品概述

**产品形态**：公开只读 Web 应用，部署在 `https://aiplanet.live`

**使用者**：工程师（单人维护 + 公开浏览），日常用于 AI 领域信息消费——每天快速浏览精选内容掌握 AI 动态，需要时通过时间线和搜索深入某个方向。

**使用方式**：
- **日常浏览**（~5 分钟）：打开精选页，扫标题和推荐理由，点感兴趣的去原文
- **深度探索**（按需）：切到时间线页，用信源类型/分类/搜索筛选，逐页浏览
- **回顾查阅**（按需）：日报页按日期查看历史精选汇总
- **微信文章解读**（按需）：切到微信文章解读页，扫精选的微信公众号文章卡片（标题+摘要+标签），点开读完整的结构化解读

**核心价值**：从 40+ 个信源中自动筛选高价值 AI 资讯，通过评分 + 规则过滤实现"精度 ≫ 召回"——每天精选约 30-40 条（vs. 原始时间线数百条），降低信息噪音。

## 页面与功能

### 精选页（`/`，首页）

产品的核心入口，是所有曾被 AI 选入精选的高价值内容的**累积归档**——把历次精选（每轮 top-40）选出的不同条目去重汇总，按发布时间从新到旧分页浏览（第 1 页即最新精选，覆盖"5 分钟扫一遍"的日常用法）。

**内容卡片包含**：
- 信源图标 + 信源名称
- 中文标题
- 中文摘要
- 推荐理由（解释为什么这条值得看）
- "精选"标记 + 分数标签（数字分数，颜色编码：≥80 高分、65-79 中等、<65 低调）
- 话题标签（最多 4 个受控词汇标签）
- 媒体资产（文章配图，可点击查看原图）
- 关联讨论（同一事件在其他信源的报道数量，悬停可查看信源列表）
- 发布时间
- 点击标题 → 在新标签页打开原文

**筛选功能**：
- 分类筛选：模型 / 产品 / 行业 / 论文 / 技巧（5 个分类）
- 搜索：匹配标题、正文、来源名、作者和中文标题；3 字及以上走全文搜索，1-2 字在短字段（标题/来源名/作者/中文标题）中兜底匹配
- 分页：底部数字页码分页控件，形态同时间线页（第 1 页与最后一页固定可见、当前页±2、… 省略、可点任一页码直接跳转、上一页/下一页箭头）；按发布时间倒序，每页约 40 条

### 时间线页（`/all`）

完整的按时间排列的内容流，用于深度浏览和探索。

**内容卡片**：与精选页类似——所有条目显示分数标签，被精选的条目额外显示"精选"标记和推荐理由。

**筛选功能**：
- 分类筛选：同精选页（5 个分类）
- 信源类型筛选：全部 / 一手信源（官方源）/ 资讯 / 推文（3+1 选项）
- 搜索：同精选页，匹配标题、正文、来源名、作者和中文标题
- 分页：底部数字页码分页控件——第 1 页与最后一页固定可见、当前页左右各 2 个相邻页、跳号处用 … 省略、可点任一页码直接跳转、含上一页/下一页箭头（每页约 40 条）

### 日报页（`/daily`）

按日期组织的精选内容归档。

**页面结构**：
- 日期档案侧边栏：列出近期有数据的日期，可点击切换
- 日期导航：← 前一日 / 后一日 → 箭头按钮
- 主内容区：当天精选内容按分类分组展示
- 顶部 header：显示 VOL 编号（格式 `VOL.YYYY.MM.DD`）、故事数量、日期

### 关于页（`/about`）

产品信息和透明度展示。

**内容**：
- 产品定位说明
- 信源池表格：列出所有信源的标识、名称、等级（T1/T1.5/T2）、状态、类型；表格上方有搜索框可过滤信源
- 评分维度解释：5 维评分（相关性、信息密度、时效性、权威性、工程价值）及权重
- 设计原则
- 致谢（项目引用和相关链接）
- 维护者联系方式 / GitHub 链接

### 微信文章解读页（`/wechat`）

独立 tab，展示来自订阅微信公众号的文章中"值得阅读"的那些，每篇配一份结构化解读。与主时间线/精选不同，这里点开是站内详情页（而非跳原文）。

**列表卡片包含**：
- 公众号头像 + 公众号名称（作者）
- 原文标题
- 摘要（文章概况首段）
- 受控词汇话题标签
- 发布时间
- 推荐等级徽标（必读 / 值得一看 / 可跳过）——与详情页"价值判断"模块的推荐等级一致
- 整张卡片可点击 → 站内解读详情页 `/wechat/<slug>`

**列表行为**：
- 展示进入"值得阅读列表"的文章，按发布时间从新到旧排列
- **收录口径偏召回**：每篇文章带一个**推荐等级**徽标（必读 / 值得一看 / 可跳过，列表卡片与详情页均显示）；由于偏召回，列表中**可能出现个别推荐等级为"可跳过"的文章**（它们有次级可参考价值）——这是产品有意的取舍，不是错误。"进入列表"与"推荐等级"是两个独立信号
- 分页：底部数字页码分页控件，形态同时间线页（第 1 页与最后一页固定可见、当前页左右各 2 个相邻页、跳号处 … 省略、可点任一页码直接跳转、含上一页/下一页箭头）（每页约 50 条）
- v1 无分类/信源/搜索筛选（WeChat 专属话题标签 ≠ 站点分类）

### 解读详情页（`/wechat/<slug>`）

产品中唯一的站内条目详情页（其余页面点标题跳原文）。独立可分享 URL。

**展示**：
- "‹ 返回列表"链接（保留来源分页上下文）
- 原文标题、公众号名称 + 发布日期、话题标签
- 完整结构化解读，分模块呈现：文章概况 / 独特亮点 / 可动手实践 / 可复用认知 / 关键词 / 价值判断 等——**模块集合随文章而变**，部分文章含额外模块（如产品方向洞察）
- 可经标题/来源到达原文微信链接

### 条目跳转（点击标题）

精选页 / 时间线 / 日报的卡片：点击标题在新标签页直接打开原文链接，无站内详情页。**唯一例外**是微信文章解读：其卡片点击进入站内解读详情页 `/wechat/<slug>`（见上）。

## 验收侧重

**三维均衡覆盖**：内容质量、功能完整性、视觉/交互体验同等重要。

| 维度 | L1 影响 | L2 影响 |
|------|---------|---------|
| **内容质量 + 信息时效** | 精选页描述详细覆盖评分、推荐理由、信源质量 | 验证条件包含内容语义准确性、每日有新内容、中文质量 |
| **功能完整性 + 流程可用** | 所有页面和交互功能均完整描述 | 每个筛选器/搜索/分页/跳转都有具体判定条件 |
| **视觉 + 交互体验** | 桌面和移动端布局均纳入描述 | 排版、响应式、加载状态、空状态都有可观测条件 |

**设备范围**：桌面端和移动端同等验收。

**微信文章解读功能的侧重（与全站三维均衡不同，本轮对齐）**：**功能流程 + 视觉交互高优先**——列表→详情→分享流程、导航/分页/边界处理、暗色风格一致性与响应式是本轮验收重点，L2 在这些维度给具体判定条件。**解读内容质量本轮不验**：结构化解读是否忠实原文/有用、"值得读"判定是否合理，视为 summarizer 产出，L2 只验"渲染正确、中文可读、无外露转义字符"，不做内容质量/判定合理性的 human judgment（留待后续轮次，见 ux-issues.md 引导项）。

## 用户视角验证条件（L2）

### 精选页

**HP-1：精选内容加载与展示**
- 打开 `https://aiplanet.live`，页面加载完成
- 首屏（第 1 页）展示多条最新精选卡片（正常日 ≥10 条）；精选页是所有历史精选条目的累积归档，可分页向后浏览（见 HP-8）
- 每张卡片可见：中文标题、摘要、信源名称和图标、推荐理由、"精选"标记、分数标签、话题标签、发布时间
- 分数标签颜色与数值匹配（≥80 高亮、65-79 中等、<65 低调）
- 内容按日期从新到旧排列

**HP-2：精选内容质量**（human judgment required）
- 标题和摘要为可读的中文，不是乱码或纯英文原文
- 推荐理由能清晰说明为什么这条内容值得关注——pass 示例："首次系统分析 AI 基础设施扫描行为，为安全团队提供攻击面情报"；fail 示例："这是一条关于 AI 的重要新闻"
- 话题标签与内容语义一致（例如关于模型发布的文章标签包含"模型"类标签）
- 分数分布合理：高分内容（≥80）应对应重大事件或高信息密度内容，不应出现明显低质内容获得高分

**HP-3：分类筛选**
- 点击任一分类标签（模型/产品/行业/论文/技巧），页面仅展示该分类下的内容
- 再次点击或选择"全部"恢复全部内容
- 筛选后列表不为空时，所有卡片的话题与选中分类相关

**HP-4：搜索**
- 输入关键词（如"Claude"）并搜索，结果列表中的内容与关键词相关
- 搜索覆盖标题、正文、来源名、作者和中文标题；3 字及以上使用全文搜索，1-2 字在标题/来源名/作者/中文标题中兜底匹配
- 搜索来源名会返回该来源的内容；搜索作者名会返回该作者的内容
- 清空搜索恢复默认列表
- 搜索无结果时显示友好的空状态提示

**HP-5：点击跳转**
- 点击卡片标题 → 在新标签页打开原文链接
- 原文链接可访问（非 404）

**HP-6：关联讨论**
- 有关联讨论的卡片显示讨论数量
- 悬停讨论区域可查看关联的其他信源列表
- 无关联讨论的卡片不显示讨论区域

**HP-7：媒体资产**
- 有配图的卡片展示文章图片
- 图片可加载、不显示为占位符或破损图标
- 点击图片在新标签页打开原文链接（图片作为源文章的视觉入口）
- 无配图的卡片正常展示，不出现空白区域

**HP-8：分页（累积归档）**
- 精选页是累积归档：汇总**所有曾被选入精选的不同条目**（跨历次 curation run 去重，每条只出现一次），按发布时间从新到旧分页——总条目数远多于单轮 top-40（当前约 1,700+ 条，≥10 页）
- 页面底部有分页控件，形态与时间线页 TL-4 一致：显示数字页码、第 1 页与最后一页固定可见、当前页左右各最多 2 个相邻页、跳号处用 … 省略、可点任一可见页码直接跳转、含上一页/下一页箭头
- 点击下一页或某个页码，加载该页内容，不与上一页重复
- 分类筛选 / 搜索生效时，分页总数与最后一页随筛选结果变化
- 处于第 1 页时不显示上一页箭头，处于最后一页时不显示下一页箭头；总页数为 1 时不显示分页控件
- 越界页码（超过最后一页）clamp 到最后一页，不显示误导空态

### 时间线页

**TL-1：时间线加载与展示**
- 打开 `/all`，展示完整时间线内容
- 每页展示多条内容卡片（约 40 条）
- 所有条目显示分数标签
- 被精选的条目额外显示"精选"标记和推荐理由
- 内容按时间从新到旧排列

**TL-2：信源类型筛选**
- 点击"一手信源"，仅展示官方源的内容
- 点击"资讯"，仅展示资讯类源的内容
- 点击"推文"，仅展示 X/Twitter 来源的内容
- 各筛选结果内的信源类型一致

**TL-3：分类筛选 + 搜索**
- 分类筛选行为同精选页（HP-3）
- 搜索行为同精选页（HP-4），包括来源名、作者、中文标题和 1-2 字短字段兜底
- 分类和信源类型可以组合使用

**TL-4：分页**
- 页面底部有分页控件，显示数字页码（而非仅"上一页/下一页"两个按钮）
- 页码始终包含第 1 页和最后一页，最小/最大页码一眼可见
- 当前页高亮，其左右各最多 2 个相邻页码可见
- 首页/末页与当前页窗口之间存在跳号（间隔 >1 页）时，用 … 省略号占位
- 可点击任一可见页码直接跳到该页，而非只能逐页点上一页/下一页
- 点击下一页或某个页码，加载该页内容，不与上一页重复
- 翻页后可返回上一页；处于第 1 页时不显示上一页箭头，处于最后一页时不显示下一页箭头
- 总页数为 1 时不显示分页控件
- 形态示例（共 N 页、当前第 8 页，N≥10）：`‹ 上一页 1 … 6 7 [8] 9 10 … N 下一页 ›`

### 日报页

**DY-1：日报加载与结构**
- 打开 `/daily`，展示最近有数据的日期的精选汇总
- 页面顶部显示 VOL 编号（格式 `VOL.YYYY.MM.DD`）、故事数量、日期
- 内容按分类分组展示

**DY-2：日期导航**
- 侧边栏显示近期有数据的日期列表
- 点击某个日期，主内容区切换到该日期的精选内容
- ← → 箭头可在相邻日期间导航
- 最新日期的"后一日"按钮隐藏（不可见）

**DY-3：日报内容一致性**
- 日报页当天的内容条目应与当天被选入精选的条目一致（同一天的相同精选结果；这些条目即精选归档中该日期的部分，正常出现在精选页第 1 页附近）
- 分类分组正确（同分类的条目在同一区块内）

### 关于页

**AB-1：信源池展示**
- 打开 `/about`，展示信源池表格
- 表格包含信源标识、名称、等级、状态、类型信息
- 信源数量 ≥20 条（产品正常运行的基本保障）
- 等级分布可见（T1/T1.5/T2）

**AB-2：信源搜索**
- 信源表格上方的搜索框可输入关键词
- 输入后表格内容被过滤，仅显示匹配的信源

**AB-3：评分解释**（human judgment required）
- 展示 5 个评分维度（relevance、density、recency、authority、engineering）及其权重说明
- 维度名称和权重数值清晰可读

**AB-4：链接可达**
- 页面上的 GitHub 链接、致谢中的外部链接等可正常访问

### 微信文章解读页

> 本节侧重功能流程 + 视觉交互（本轮高优先）。解读内容质量本轮不验，见 WX-6。

**WX-1：侧栏入口与导航**
- 全站各页（`/` `/all` `/daily` `/about` `/wechat`）左栏均含「微信文章解读」链接
- 点击进入 `/wechat`；当前在 `/wechat` 时该链接呈高亮（active）态

**WX-2：列表加载与卡片**
- 打开 `/wechat`，展示多张进入"值得阅读列表"的微信文章卡片（正常 ≥10）
- 每张卡片可见：公众号头像 + 名称、原文标题、摘要、话题标签（≥1）、推荐等级徽标（必读/值得一看/可跳过）、发布时间
- 卡片按发布时间从新到旧排列
- **整张卡片**可点击进入详情（不只标题区域）

**WX-3：列表收录口径**
- `/wechat` 列表展示进入"值得阅读列表"的文章；未进入该列表的文章不出现在列表中，直接访问其 `/wechat/<slug>` 显示 404 页（无法访问）
- 收录偏召回：列表中可出现个别详情页推荐等级为"可跳过"的文章（有意取舍，非错误）；本条不对"是否真的值得读"做质量判断

**WX-4：分页与上下文保留**
- 列表底部有分页控件，形态与时间线页 TL-4 一致：显示数字页码、第 1 页与最后一页固定可见、当前页左右各最多 2 个相邻页、跳号处用 … 省略、可点任一可见页码直接跳转、含上一页/下一页箭头
- 翻页加载新内容、不与上页重复、可返回上一页
- 越界页码（超过最后一页）回到最后一页，**不**显示"暂无微信文章解读"误导空态
- 从第 N 页点开的详情，"‹ 返回列表"回到第 N 页（保留分页上下文）

**WX-5：详情页渲染**
- 点卡片 → `/wechat/<slug>`，展示该文章结构化解读
- 解读分模块呈现，模块标题渲染为结构化标题（非裸 markdown 源码）；至少含 文章概况/独特亮点/可动手实践/可复用认知/关键词/价值判断（部分文章有额外模块）
- 含"‹ 返回列表"、公众号名称 + 发布日期、话题标签
- URL 可独立分享：在新标签直接打开 `/wechat/<slug>` 仍正常渲染

**WX-6：内容渲染正确性**（只验渲染，不验解读质量）
- 标题、摘要、解读正文为可读中文，不是乱码或纯英文原文
- 无外露转义字符（如标题/正文出现字面 `\n`）
- 解读是否忠实原文/有用、"值得读"判定是否合理——**本轮 de-scoped，不做判断**（验收侧重对齐结果）

**WX-7：边界——未知 slug 404**
- `/wechat/<不存在的 slug>` 返回 404，且 404 页在站点框架内：暗色主题、含侧栏导航 + "返回列表"入口，不是裸白页

**WX-8：响应式与风格一致**（wechat 专属补充，通用响应式见 RS-*）
- 暗色配色、字体、卡片样式与时间线页 `/all` 一致
- 移动端（~390px）详情内的表格不被挤压（可横向滚动），正文不需横向滚动

**WX-9：空状态**
- 当"值得阅读列表"确实没有任何文章时，`/wechat` 显示友好空态提示（如"暂无微信文章解读"），而非报错或空白页

### 响应式与视觉

**RS-1：桌面端布局**

**RS-4：空状态**

- 信源种类覆盖：官方源、资讯、推文等

- 浏览器兼容性（仅需验证主流浏览器 Chrome/Safari）

- 内容的中文标题、摘要、推荐理由能正常展示
- 网站 `https://aiplanet.live` 可正常访问

## Defaulted Decisions

| 决策 | 默认值 | 理由 |
|------|--------|------|
| 分数标签颜色阈值 | ≥80 高亮、65-79 中等、<65 低调 | 基于当前产品展示的实际阈值 |
| 精选页内容口径 | 所有曾被精选的不同条目（跨历次 run 去重），按发布时间倒序分页 | 用户对齐：精选是 AI 优选的 best-of **累积归档**，非仅最新一轮 top-40；排序与全站 feed 一致 |
| 精选页"正常日"最少条数 | ≥10 条（第 1 页） | 精选页是累积归档；第 1 页展示最新精选，正常日 ≥10 条，10 为保守下限 |
| 翻页每页条数 | 约 40 条（/、/all、/wechat 一致） | 基于各页面的实际加载量 |
| 分页控件形态 | 数字页码 + 首末页固定 + 当前页±2 + … 省略 + 上一页/下一页箭头 | 用户对齐：要能一眼看到首末页、可直接点多个页码；当前页±2 让中间有 5 个可点页码，移动端可换行不挤压 |
| 浏览器范围 | Chrome + Safari | 覆盖桌面和移动端主流浏览器 |
| 信源池最少数量 | ≥20 条 | 当前约 41 个信源，20 为保守下限 |
| 微信文章解读内容质量验收 | 本轮 de-scoped（L2 只验渲染正确） | 用户对齐：功能流程 + 视觉交互优先，解读内容质量先不看 |
| 解读详情模块集合 | 随文章而变（核心 6 模块 + 部分文章额外模块如产品方向洞察） | 实测 summarizer 产出模块数不固定，不硬断言"恰好 6 个" |
| `/wechat` 每页条数 | 约 50 条 | 基于当前列表实际加载量 |
| 微信解读列表收录口径 | 进入"值得阅读列表"即收录（偏召回，可含"可跳过"等级文章） | 列表展示与详情可达性同口径；"收录"与每篇的推荐等级（必读/值得一看/可跳过）是两个独立信号 |
