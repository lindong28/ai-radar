# 多维语义评分

> [Developer] · 2026-09-20 · 离线候选，生产尚未采用。依据用户选择：先做好各维判断标准与组合，不受旧六维/零权重约束，不以数值校准补偿语义误差。

## 判断什么

面向关注 AI 进展的一般读者，评价输入新闻所传达的阅读价值，拟合冻结 AIHOT 可见分。一次 Flash 调用输出三个有理由的 0–10 整数分；代码组合，不让模型再自由修改总分。维度分是可检查的中间判断，不是具有人工真值的解释，也不声称三个维度统计独立。

| 维度 | 定义与边界 | 0 / 2 / 5 / 8 / 10 锚点 |
| --- | --- | --- |
| 影响 `impact` | 完整输入（含已有引用）所报道事件或知识对能力、实际使用、行业格局、治理或公众认知的影响；不是转发动作、话题本身宏大或作者知名 | 无可识别影响 / 个人窄用途、小变更 / 领域内明确进展或有后果的行动、表态 / 跨领域重大改变或重要决策转向 / 罕见范式变化 |
| 信息增量 `information_gain` | 这条内容让读者新增的事实、理解或方法；不重复计算影响范围 | 无增量口号 / 少细节转述 / 具体新事实、可复用方法 / 关键新结果或深入独到分析 / 改变理解的罕见发现 |
| 实质支撑 `evidence` | 输入对核心主张提供的具体说明与可用性；不是外部事实核验，也不是篇幅或身份奖励 | 主张不可辨 / 空泛断言 / 主体、变化、作用清楚或步骤可操作 / 数据、实验、机制和限制的有力支撑 / 充分且多面的支撑 |

锚点间可用整数。短新闻可凭明确发布事实获得中高支撑分；长文不会因字数自动得分。按输入描述的当时事件判断，不以模型知识截止否认新型号或未来日期；不臆造链接、视频或未提供的正文。来源只帮助理解主张，不乘来源等级。汇总不把条目数量累加为事件影响。

## 组合

`score = 5 * impact + 3 * information_gain + 2 * evidence`，自然落在整数 0–100，无裁剪、截距、池内排名或后置校准。50% / 30% / 20% 表达影响优先、增量其次、支撑补充；这是预设实验权重，不是 AIHOT 内部公式或拟合最优值。三个维度均实际影响结果，不输出零权重维度。纯函数位于 `src/airadar/scorer/semantic.py`，评测入口 `--mode semantic`。

模型响应顶层先 `reason`，随后各维对象；每维也先 `reason` 后 `score`。全局理由解释该条的核心价值，各维理由指向输入依据。每维理由缺失、后置或分数越界均记录失败，不补造理由、不丢题重算 MAE。原响应与投影总分分别留档。

## 本次实验边界

S1为初始三维定义（`semantic-news-value-v1.json`）。S2（`semantic-news-value-v2.json`）只将impact评估单位澄清为全文中的事件，并补齐治理/公众认知影响；原创和细节留给另两维，不因转述再次扣影响分。不改权重。开发MAE11.385→11.015，冻结S2进入新回归；同规则直接对照D1只对应S1，不把S2对D1的差异都归因于显式分维。

题库不变，沿用 `aihot-score-pointwise/v1` 的固定开发200（seed `score-dev-20260920`）。B0旧六维与C2直接新闻重要性保留对照；另用**完全相同的三维刻度与50/30/20**、但只输出总分的直接对照，避免把换标尺与分维机制混为一谈。结果只覆盖这些实现，不得推断所有多维或直接评分的普遍优劣。

先3题 smoke，随后同题开发比较，至多两次有归因的开发修订。开发优于B0后冻结，再取排除旧200回归题的新200，重建同题B0/C2。旧回归已经给过诊断，不再称未见；事件级及更早历史曝光未完全核实。主指标仍为逐题 MAE；没有绝对达标线，不增加 LLM 判官。原文、gold、生产路径均不修改。

参照研究：当前有3,475条成对题，但没有已取得的 AIHOT 私有评分定义或可反复调用的评分接口，自一致性未核实。开发材料上的粗分档探针10/20（中段分布6/8/6，恒报中档8/20），只说明中段假设尚不充分；未覆盖最低/最高档，不是模型成绩或完整规则验证。留存原件于本轮 support，不能拿该探针证明三维设计已有效。
