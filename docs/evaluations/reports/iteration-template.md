# 迭代结论模板

> 每轮实例落在对应根 runs 分区的 conclusion.md；这里不存运行成绩。

## 对象与结论

填写对象、版本、窗口、基线/候选、这次能证明及不能证明什么。

## L1 计算逻辑

①优化对象 · ②评测题 · ③判官 · ④自动指标 · ⑤判官校验：分别记状态、分母及适用范围；不适用就写不适用。

## L2 数据资产

输入、输出、指标、人评、判词日志、归因、台账分别给本轮落点及实际存量；费用未知不填零，计划/实际并发分开。

## L3 治理

身份、可比性、评价provenance、归因准入、caller：记录已执行的检查及未覆盖边界。

## 后续

按对象写已达成、未达成、未处置finding及owner；没有有效读数不声称改善。
