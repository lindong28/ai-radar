### 前轮：C1 direct-ai-impact（历史结果）

结论：**完成一轮离线评测与候选优化实验，C1未通过独立回归，不采纳；生产prompt不变。** C1只增加一句“AI对社会、经济、就业、能源与资源的直接影响也属于AI相关”的范围说明。开发集两项提高，但回归precision微降，不能因降幅小而临时放宽预定准则；也不声称该差异统计显著。

| 固定子集 | 当前源码基线 precision / recall | C1 precision / recall | 同题比较 |
| --- | --- | --- | --- |
| dev：600题，80正520负、54来源 | 70/154 = 45.45% / 70/80 = 87.50% | 73/159 = 45.91% / 73/80 = 91.25% | 两项提高 |
| regression：400题，42正358负、44来源 | 33/95 = 34.74% / 33/42 = 78.57% | 35/101 = 34.65% / 35/42 = 83.33% | recall提高，precision下降，不接受 |

回归中多保留2条正例，净增4条误收。新增5条误收均来自buzzing_hn，同时修复1条suno_blog误收；这些是逐题观察，不证明来源映射或参考标签错误。开发集原先84条误收中56条来自buzzing_hn，后续分析需要区分AI相关性和AIHOT实际选题边界，不能只扩大放行范围。
